# BOZER TTS — attribution de la voix française MLS

BOZER utilise le checkpoint vocal français Piper dérivé de **fr_FR-mls-medium**.

- Langue : français de France (fr_FR)
- Qualité du modèle indiqué par sa fiche : medium
- Corpus : Multilingual LibriSpeech (MLS), OpenSLR 94
- Licence du corpus indiquée sur la fiche du modèle : Creative Commons Attribution 4.0 International (CC BY 4.0)
- Profil utilisé dans la conversion Sherpa-ONNX intégrée : identifiant de locuteur 1, annoncé comme masculin dans la configuration du modèle Sherpa.

Références :
- Fiche officielle Piper : https://huggingface.co/rhasspy/piper-voices/blob/main/fr/fr_FR/mls/medium/MODEL_CARD
- Corpus MLS / OpenSLR 94 : https://openslr.org/94/
- Projet Sherpa-ONNX : https://github.com/k2-fsa/sherpa-onnx
- Licence CC BY 4.0 : https://creativecommons.org/licenses/by/4.0/

Mention d'attribution :
« fr_FR-mls-medium — modèle vocal français du projet Piper, entraîné sur le corpus Multilingual LibriSpeech (MLS), OpenSLR 94. Corpus sous licence CC BY 4.0. »

BOZER règle le profil de locuteur, le débit de parole et les paramètres de génération. Ces réglages ne constituent pas un réentraînement du modèle ni la création d'une voix originale BOZER. L'écoute sur des appareils réels reste nécessaire avant de qualifier la voix de naturelle.
