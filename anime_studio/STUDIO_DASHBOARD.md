## Production rules
- A document, prompt, still image, storyboard frame, animated shot and finished episode are different deliverables. Never count one as another.
- Every generated asset receives an ID and a review status.
- Do not mark an asset APPROVED without creator review.
- Keep proposals separate from confirmed canon.
- Never overwrite an approved reference silently; create a revision.
