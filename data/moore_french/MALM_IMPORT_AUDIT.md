# Import MALM — données candidates

- Dépôt source : https://github.com/progressio-media/malm-data
- Fichier source : `lexicon.json`
- Licence déclarée par le dépôt source : MIT (à conserver avec attribution).
- Provenance listée dans le fichier : SRC-17, SRC-11, SRC-13, SRC-07, SRC-04 et SRC-06.
- Les droits des ouvrages tiers cités dans les métadonnées MALM n'ont pas tous été confirmés indépendamment.
- 10234 paires françaises–mooré uniques ajoutées dans cette file.
- 23 doublons exacts ont été fusionnés; 1 paire déjà présente dans le dictionnaire BOZER a été ignorée.
- Toutes les lignes sont des candidates non validées. Aucune n'est rendue par le traducteur par défaut.
- Les signes diacritiques sont conservés; les formes ambiguës produisent un résultat `ambiguous` au lieu d'un choix arbitraire.

Ce fichier est une base de recherche et de revue linguistique, pas un dictionnaire certifié.
